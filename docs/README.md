## 🏥 About MESMTF

The Medical Expert System for Malaria and Typhoid Fever (MESMTF) is a comprehensive web-based system designed for the Ministry of Health and Social Services. It provides e-Health services including medical records, appointments, diagnosis, treatment, pharmacy, drug administration, and reporting.
